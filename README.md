## ✨ Fitur Interaktif

Buka panel di bawah ini untuk melihat detail masing-masing fitur keren yang ada di dalam aplikasi!

<details>
<summary><b>🚨 Laporan Darurat Tanpa Login & GPS</b></summary>
<br>
<blockquote>
Sistem pelaporan darurat yang memungkinkan warga mengirimkan peringatan detik itu juga! 
Dilengkapi dengan integrasi <b>Peta Leaflet</b> interaktif. Pengguna cukup klik "Gunakan GPS Saya", dan pin merah akan otomatis berpindah ke lokasi presisi mereka saat ini.
</blockquote>
</details>

<details>
<summary><b>🔑 Google Single Sign-On (SSO)</b></summary>
<br>
<blockquote>
Tidak perlu repot mengisi formulir pendaftaran panjang. Klik tombol <b>"Masuk dengan Google"</b>, dan pengguna langsung terdaftar serta memiliki dasbor pribadinya sendiri dalam hitungan detik.
</blockquote>
</details>

<details>
<summary><b>📊 Dasbor Admin Modern & Manajemen Pengguna</b></summary>
<br>
<blockquote>
Admin dapat mengelola seluruh tiket, mengubah statusnya (Pending, Diproses, Selesai), dan menggunakan halaman Manajemen Pengguna untuk menaikkan/menurunkan peran (<i>role</i>) anggota secara <i>real-time</i> tanpa me-<i>reload</i> halaman.
</blockquote>
</details>

<details>
<summary><b>💬 Sistem Diskusi Tiket (Komentar)</b></summary>
<br>
<blockquote>
Pengguna dan admin dapat berdiskusi langsung di dalam tiket laporan layaknya aplikasi <i>chatting</i>, lengkap dengan dukungan unggahan foto bukti perbaikan.
</blockquote>
</details>

## 🚀 Panduan Instalasi Cepat

Ingin mencoba menjalankan aplikasi ini di komputer Anda? Sangat mudah! Buka bagian di bawah ini.

<details>
<summary><b>💻 Klik di sini untuk melihat langkah Instalasi</b></summary>
<br>

1. **Kloning Repositori**
   ```bash
   git clone https://github.com/username-anda/ticketlapor.git
   cd ticketlapor
   ```

2. **Instal Dependensi (Backend & Frontend)**
   ```bash
   composer install
   npm install
   ```

3. **Pengaturan Lingkungan (.env)**
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
   > 🔴 **PENTING:** Atur koneksi database Anda di file `.env`, lalu tambahkan *Client ID* Google Anda:
   > ```env
   > GOOGLE_CLIENT_ID=client_id_anda.apps.googleusercontent.com
   > GOOGLE_CLIENT_SECRET=secret_anda
   > GOOGLE_REDIRECT_URI="${APP_URL}/auth/google/callback"
   > ```

4. **Jalankan Database Migration & Seeder**
   ```bash
   php artisan migrate:fresh --seed
   ```

5. **Nyalakan Mesin!** (Buka 2 Terminal)
   ```bash
   # Terminal 1: Compile CSS/JS secara real-time
   npm run dev
   ```
   ```bash
   # Terminal 2: Jalankan server Laravel
   php artisan serve
   ```
   Aplikasi Anda sekarang berjalan di `http://127.0.0.1:8000` 🎉
</details>

## ❓ FAQ (Tanya Jawab)

<details>
<summary><b>1. Mengapa menggunakan Livewire alih-alih React/Vue?</b></summary>
<blockquote>Karena Livewire 3 dipadukan dengan Laravel 11 menawarkan kecepatan pengembangan yang luar biasa. Kita bisa mendapatkan pengalaman SPA (Single Page Application) penuh tanpa perlu membangun API terpisah, sehingga sangat efisien untuk aplikasi berskala menengah ke atas.</blockquote>
</details>

<details>
<summary><b>2. Apakah fitur Leaflet Map membutuhkan API Key berbayar?</b></summary>
<blockquote>Tidak. Kami menggunakan OpenStreetMap yang 100% gratis dan bersifat Open Source, sehingga Anda tidak perlu khawatir tentang biaya tagihan peta.</blockquote>
</details>
